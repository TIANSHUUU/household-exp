# 活动安排页 日期标签强化 设计文档

日期：2026-07-27

## 背景

`activity.html` 上线后，用户反馈按日期分组的标签太不显眼（12px、浅灰色、无背景），容易被忽略。曾考虑改成完整日历视图，但权衡后选择更轻量的方案：保留现有「待定/已确认」两区块 + 按日期分组的列表结构，只强化日期标签本身的视觉样式。

## 决策（已与用户确认）

强化 `.date-label` 样式，使其从辅助性小字变成醒目的小标题栏：

- 字号 12px → 15px，字重 600 → 700
- 文字颜色 `var(--sub)`（浅灰）→ `var(--text)`（主文字色）
- 新增浅色背景条 + 左侧 4px 强调色（`var(--accent)`）竖条
- 文字前加 🗓 图标
- 纯 CSS 改动，不改 `fmtDate()` 的文字内容（仍是"7月30日 · 周四"格式），不改数据结构或交互逻辑
- 待定、已确认两个区块共用同一套 `date-group`/`date-label` 组件，样式自动同步生效

## 范围

仅修改 `activity.html` 中 `.date-label` 的 CSS 规则，以及渲染该标签的 JS 模板字符串（加图标）。不涉及 `index.html`（其 `.date-label` 保持原样，本次改动只针对活动安排页）。
