# 购物清单 商品链接 设计文档

日期：2026-07-28

## 背景

购物清单条目目前只有名字（快速输入回车即加），用户想给条目附一个可选的商品链接（比如某个牌子的购买链接）。

## 决策（已与用户确认）

- `shopping_items` 表新增一列 `link`（text，可选，URL）。
- 每个条目在名字和删除按钮之间新增一个 🔗 图标：
  - 未设置链接时：淡色按钮，点击弹出浏览器原生 `prompt()` 输入/粘贴链接，确定后 `siPatch` 保存。
  - 已设置链接时：图标变亮色，本身就是可点击的 `<a target="_blank">`，直接跳转，不再弹窗。
- **取舍（已确认）**：链接一旦设置，图标的点击行为从"编辑"变成"跳转"，不再提供编辑入口——要换链接需要删掉这条重新加。名字的编辑（点名字→行内编辑→失焦保存）完全不受影响，两者互相独立。
- 快速添加（回车加条目）流程不变，新条目的 `link` 初始为空，链接只能加完之后通过图标补充。
- 复制清单（⧉ 复制）时一并复制 `link`。
- 安全：只有 `http://`/`https://` 开头的值才会渲染成真正可点击的链接，其他情况静默不显示图标（不报错，选填字段不值得为格式问题打断用户）——和活动页的地址链接字段同一套规则。

## 范围

仅修改 `shopping.html`（渲染、DB 层新增/复用 patch、复制逻辑）和 Supabase `shopping_items` 表结构（新增一列，需手动执行 `ALTER TABLE`）。不涉及 `index.html`/`activity.html`。
