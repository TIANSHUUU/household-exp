# 活动安排页 时间范围与地址链接 设计文档

日期：2026-07-27

## 背景

`activity.html` 现有的"精确时间"字段只能填一个时间点（隐含为开始时间），用户想要能写出一段时间范围（比如 19:00–21:00）。另外希望能给活动附一个可点击跳转的地址链接（比如 Google Maps）。

## 决策（已与用户确认）

### 1. 结束时间（可选）

- `activities` 表新增一列 `time_end`（text，可选，`HH:MM` 格式）。不重命名现有的 `time` 列（它继续隐含表示开始时间），避免不必要的迁移。
- 表单"精确时间"区域从一个输入框改为并排的开始/结束两个 `<input type="time">`，结束时间选填。
- 展示逻辑（在现有的"时段 + 精确时间 → 全天兜底"基础上扩展）：
  - 只填开始时间 → 显示 `19:00`
  - 开始 + 结束都填 → 显示 `19:00–21:00`
  - 都不填 → 沿用现有时段/"全天"兜底逻辑
- 校验：如果开始和结束都填了，且结束 ≤ 开始，提交时用现有的 `alert()` 校验方式拦截，不允许提交。

### 2. 地址链接（可选）

- `activities` 表新增一列 `link`（text，可选，存放完整 URL）。
- 表单新增"地址链接（选填）"文本输入框。
- 有值时，该条目的备注行末尾追加一个可点击的 📍 图标（`target="_blank"`，新标签页打开）。
- 安全限制：只有当值以 `http://` 或 `https://` 开头（大小写不敏感）时才渲染为可点击链接；否则静默不显示图标（不报错，因为是选填字段，不值得为格式错误打断用户）。

两个新列都可为空，不影响任何现有记录（老记录这两列读出来是 `null`，前端已有的 `|| ''` 归一化模式会照常处理）。

## 范围

仅修改 `activity.html`（表单、渲染、DB 层的 insert/update 字段列表）和 Supabase `activities` 表结构（新增两列，需要手动在 SQL editor 执行 `ALTER TABLE`）。不涉及 `index.html`/`shopping.html`。
